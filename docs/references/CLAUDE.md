# CLAUDE

Three reference lists (`books.md`, `papers.md`, `websites.md`), per
`docs/planning/knowledge-architecture.md`'s reference section and
`docs/planning/backlog.md` E6. Each is populated from what
`docs/handbook/` actually cites -- not a general bibliography, and not
somewhere to add a reference that no Handbook entry cites yet.

Written 2026-08-17 alongside the sixteen Handbook entries (E3/E4) that
first gave these files something real to list. `websites.md` currently
has no entries -- every citation so far is a book or paper -- and says so
explicitly rather than being left empty.

**Maintenance rule:** whenever a Handbook entry's own References section
changes (a citation added, removed, or corrected), update the matching
entry here in the same change (Blast Radius, `docs/practices.md`) --
these files are a derived index of what the Handbook cites, and drift
the same way `docs/repository-manifest.md` does if only one side is
touched.
