## When to Add an Entry

Add a citation here the moment a Handbook entry (or any other document
under `docs/`) cites a website -- documentation for a specific tool or
library, a maintained reference page without a book/paper equivalent, or
similar -- in the same change that adds the citation, per the Blast
Radius rule (`docs/practices.md`). Prefer a durable citation (a book or
paper, with an edition/year that won't change under the reader) over a
web page where an equivalent exists, since a URL can move or its content
change in a way a published edition cannot.
